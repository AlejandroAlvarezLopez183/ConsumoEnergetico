# Cómo contribuir a SNRGY Viviendas

1. Selecciona una tarea `Ready` que tengas asignada.
2. Confirma los criterios de aceptación. Si no están claros, pregunta antes de programar.
3. Crea una rama que incluya el número del issue.
4. Implementa el cambio mínimo; no hagas refactorizaciones fuera del alcance.
5. Ejecuta `python scripts/check_js_syntax.py` y los pasos de prueba descritos en el issue.
6. Abre un Pull Request con el issue enlazado, resumen, pruebas, capturas si aplica y riesgos.
7. Atiende los comentarios de revisión y espera aprobación antes de hacer merge.

No incluyas datos personales de residentes, archivos con contraseñas o claves administrativas en commits, issues, capturas ni prompts de IA.
